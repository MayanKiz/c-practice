## Run a Program

Compile one file at a time from the repository root:

```bash
gcc Assignment/Week-01/02_add_two_numbers.c -o program
./program
```

Replace the path with the program you want to run. These are practice examples; check your official assignment sheet for any different question wording or input/output requirements.
