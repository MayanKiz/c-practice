## Compile and run

Run one program at a time from the repository root:

```bash
gcc Assignment/Week-01/02_add_two_numbers.c -o program
./program
```

Replace the file path with the program you want to run. GCC is required. These are practice solutions; compare the question wording and required input/output format with your official AKTU assignment sheet.
