# Python Practice

A dedicated place for Python fundamentals, problem-solving, automation scripts, and AI/ML experiments.

## Folders

- `01-Basics/` — variables, data types, input/output, operators, conditions, loops, and functions.
- `02-Data-Structures/` — lists, tuples, sets, dictionaries, and strings.
- `03-Problem-Solving/` — loops, functions, searching, sorting, and practice questions.
- `04-Projects/` — practical projects, scripting, and future AI/ML work.

## Run a program

```bash
python filename.py
```

Add each exercise to the topic folder that best matches it.
