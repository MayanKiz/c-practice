# C Practice

C programs collected while learning programming fundamentals and practising college exercises.

## Topics

- `01-Basics` — input/output and beginner programs
- `02-Operators` — arithmetic and bitwise operators
- `03-Conditionals` — `if`, `else`, comparisons, and decisions
- `04-Switch` — `switch-case` exercises
- `05-Loops` — loops, nested loops, number problems, and patterns
- `06-Functions` — user-defined functions
- `07-Break-Continue` — loop control
- `08-Structures` — structure-based programs
- `08-practice-set` — numbered practice questions
- `09-Misc` — miscellaneous and legacy practice
- `arrays/`, `pointers/`, `strings/`, `files/` — focused language topics

## Compile and run

```bash
gcc path/to/program.c -o program
./program
```

Each source file is a separate practice program and may have its own input/output.
