# C++ Practice

A place for C++ fundamentals, the Standard Template Library (STL), data structures, algorithms, and coding-interview preparation.

## Folders

- `01-Basics/` — input/output, data types, operators, conditions, loops, and functions.
- `02-STL/` — `string`, `vector`, `pair`, `map`, `set`, sorting, and common algorithms.
- `03-Data-Structures/` — arrays, linked lists, stacks, queues, trees, heaps, and graphs.
- `04-Algorithms/` — searching, sorting, recursion, greedy methods, and dynamic programming.
- `05-Practice/` — standalone problems and interview practice.

## Compile and run

```bash
g++ filename.cpp -std=c++17 -o program
./program
```

Practise one problem at a time and consider time and space complexity.
