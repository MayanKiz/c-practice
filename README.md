# Programming Practice

A personal repository for learning programming, solving problems, and building strong fundamentals for software engineering interviews.

## Languages

- [C](C/README.md) — fundamentals, college practice, and beginner exercises.
- [C++](C++/README.md) — C++ basics, STL, data structures, algorithms, and interview preparation.
- [Python](Python/README.md) — Python fundamentals, scripting, automation, and future AI/ML practice.

## Layout

Existing C practice is organized under `C/`, retaining its topic folders and source files. Dedicated `C++/` and `Python/` folders provide a clear place for future practice, each with topic-based subfolders and README guides.

## How to use

1. Open the language folder you want to practise.
2. Read its README for topics and suggested order.
3. Run programs locally and experiment with the input.
4. Focus on understanding the approach and edge cases instead of copying solutions....
