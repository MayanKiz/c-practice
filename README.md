
# C Programming Practice

A collection of beginner-friendly C programming exercises covering fundamental syntax, control flow, loops, arrays, and structures. Each exercise is kept in a separate source file so concepts can be studied and compiled independently.

## Topics Covered

- Basic output and arithmetic
- Operators and swapping values
- `if`/`else` decision-making
- `switch` statements
- Loops and counting
- `break` statements
- Arrays and searching
- Prime numbers and divisibility
- Simple calculators and menus
- Structures for storing related data
- Student, book, employee, distance, and date records

## Learning Approach

1. Read the source file and identify the inputs, processing, and output.
2. Compile it with warnings enabled.
3. Run it with normal and edge-case inputs.
4. Modify the program and observe the result.
5. Try implementing the exercise again without looking at the original solution.
